.. _spkg_accessible_pygments:

accessible_pygments: Accessible Pygments styles
================================================

Description
-----------

A collection of accessible Pygments styles that meet WCAG AA and
AAA contrast ratio guidelines for syntax highlighting, ensuring
code is readable by users with visual impairments.
